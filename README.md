# Factory Method Example (C#)

Проста демонстрація патерну проектування **«Фабричний метод» (Factory Method)** на мові C#.

## 💡 Як це працює

У коді реалізовано абстрактний клас забудовника (`Developer`), який визначає метод для створення будинків (`Create()`). Конкретні класи забудовників самі вирішують, який саме будинок побудувати:

- **PanelDeveloper** створює панельний будинок (`PanelHouse`).
- **WoodDeveloper** створює дерев'яний будинок (`WoodHouse`).

## 🏗 Структура класів

- `Developer` — абстрактний клас забудовника (*Creator*).
  - `PanelDeveloper` — створює панельні будинки.
  - `WoodDeveloper` — створює дерев'яні будинки.
- `House` — абстрактний клас будинку (*Product*).
  - `PanelHouse` — панельний будинок.
  - `WoodHouse` — дерев'яний будинок.
